# Treads & Tracks

**Category**: Species Movement (BASIC)  
**Classification**: basic  
**Target Mode**: Ground  
**Cost**: +0 BP  
**Base Speed**: 30 ft / round  

## Description
Continuous caterpillar tracks or rolling hub treads for synthetic chassis. Immune to difficult rough terrain; base speed 30 ft/round.

### Tactical Movement Stages (Ground)
- **Walk**: 1x Base (30 ft/rd). Default baseline movement pace for all ground locomotion.
- **Jog**: 2x Base (60 ft/rd). Hurried pace with a -2 penalty to subtlety, stealth, or precision.
- **Running**: 4x Base (120 ft/rd). Fast running pace with a -4 penalty to subtle actions; requires Athletics check (CR 10+) each minute.
- **Sprinting**: 6x Base (180 ft/rd). Maximum land sprint with a -8 penalty to subtle actions; requires Athletics check (CR 15+) each minute.
- **Crawl**: 1/2x Base (15 ft/rd). Low-profile crawl; grants +2 bonus to stealth; inflicts Prone condition.
- **Slow Crawl**: 1/4x Base (7.5 ft/rd). Deliberate stealth crawl; grants +4 bonus to stealth; inflicts Prone condition.

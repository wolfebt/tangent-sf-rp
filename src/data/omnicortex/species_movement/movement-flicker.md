# Flicker (Innate Phase Step)

**Category**: Species Movement (ADVANCED)  
**Classification**: advanced  
**Target Mode**: Flicker  
**Cost**: +3 BP  
**Base Speed**: 30 ft / round  

## Description
Innate metaphysical or cybernetic flicker teleportation granting instant 30 ft phase displacement per round.

### Tactical Movement Stages (Flicker)
- **Flicker**: 1x Base (30 ft/rd). Instant line-of-sight quantum phase step without traversing physical intervening space or provoking opportunity attacks.
- **Rush**: Up to 2x Base (60 ft/rd). Extended emergency phase surge; requires an Endurance / Stamina check (CR 15+) to avoid fatigue.

# Karma System Integration & Destiny Features

Karma represents luck, divine favor, heroic destiny, and reality-bending determination. All characters possess a baseline Karma Pool (typically 3 KP).

## Karma-Activated Features
Several specialized features spend Karma Points (KP) to trigger powerful instantaneous effects:

| Feature | KP Cost | Tactical Trigger & Benefit |
| :--- | :---: | :--- |
| **Surge** | 1 KP | Gain **1 additional Standard Action** on your turn. |
| **Seize Initiative** | 1 KP | Automatically act **First** in the initiative order for the encounter. |
| **Beginner's Luck** | 1 KP | Temporarily gain **+5 Skill Ranks** in a Novice (≤5) skill for one scene. |
| **Ultimate Effort** | 1 KP | Treat a chosen non-combat check as an automatic **Natural 20**. |
| **Inspiration** | 1 KP + cost | Transfer a Karma benefit or action surge to an ally. |
| **Karmic Blessing** | Passive | Permanently increases maximum Karma Pool capacity by **+2 KP**. |

## Faith & Devotion Progression
- **Believer**: 1/day per rank: Reroll a failed skill check without spending KP.
- **Devout**: 1/day per rank: Reroll a failed ability check without spending KP.
- **True Faith**: Karma points spent in direct service of one's deity or sacred mandate **double** their numeric effect.

# Features System Overview & Acquisition

Features (also called Feats) offer a powerful way to customize your character and make them stand out. Think of Features as special abilities, cybernetic enhancements, magical talents, or advanced martial training that go beyond a character's basic Ability Scores and Skill Ranks.

## Feature Economy & Build Point Costs
- **Standard Build Point Cost**: Every Feature costs **3 Build Points (BP)** to acquire during character creation.
- **Suggested Feature Discount**: If you choose a Suggested Feature from the list recommended for your character's Species, Faction, Origin, or Occupation, the cost is reduced by **1 BP** (costing **2 BP**).
- **Minimum Cost Floor**: Even with multiple faction, origin, or species discounts, a Feature can **never cost less than 1 BP**.

## Progression & Advanced Features
As characters gain experience, they unlock access to more advanced Features. Advanced Features require meeting prerequisite conditions, such as:
1. **Attribute Minimums** (e.g., *Agility 2*, *Intellect 3*).
2. **Skill Ranks / Stages** (e.g., *Pilot 6*, *Melee 11*).
3. **Parent Features in a Tree** (e.g., *Dodge -> Mobility*, *Two-Weapon Fighting -> Improved Two-Weapon Fighting*).
4. **Species / Biological Traits** (e.g., *3+ arms*, *Synthetics*, *Awakened*).

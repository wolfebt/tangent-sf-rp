# Scale Multipliers, Colossal Targets & Vehicle Scale

To model interactions between infantry soldiers, heavy mecha, tanks, and orbital star dreadnoughts, Tangent utilizes **Scale Multipliers**:

| Scale Tier | Size Example | Damage Multiplier | Defense Modifier | Structure Scaling |
| :--- | :--- | :---: | :---: | :---: |
| **Miniscule** | Micro-drone / Insect | x1/8 | -32 | 1/8x |
| **Tiny** | Cat / Pistol Drone | x1/4 | -4 | 1/4x |
| **Small** | Halfling / Turret | x1/2 | -2 | 1/2x |
| **Medium (Base)** | Human Soldier | **x1** | **0** | **1x** |
| **Large** | Power Armor / Bike | x2 | +2 | 2x |
| **Huge** | Walker Mecha / Tank | x5 | +4 | 5x |
| **Gargantuan** | Dropship / Gunship | x10 | +8 | 10x |
| **Colossal** | Corvette / Cruiser | x20 to x64 | +16 | 20x to 64x |

# Combat System Overview & Core Philosophy

The Tangent SF RP combat system is an action-rich, tactical d20 engine designed to model fluid gunplay, martial arts, heavy armor kinetics, energy weapons, and metaphysical powers.

## The Core Attack Formula
```text
Attack Check = d20 + Combat Skill Rank + Relevant Ability Modifier + Situational / Edge Modifiers
vs.
Target Defense DC (Opposed or Unopposed CR 15 base modified by Size, Range, Cover)
```

## Key Tactical Pillars
1. **Skill-Driven Action Economy**: Higher skill ranks unlock multiple iterative attacks and active defensive reactions per round.
2. **Opposed Defense**: Targets can actively roll Defense to evade or parry incoming strikes (Defender wins all ties).
3. **Location-Based Trauma**: Precision strikes and called shots target vulnerable limbs, sensory clusters, and vital organs.
4. **Damage Penetration & Constitution**: Armor DR and natural Constitution absorb incoming force before Health takes damage.
5. **Mortality & Bleeding**: Reaching 0 HP does not instantly kill; characters enter a tense Bleeding Out state governed by Stability Thresholds.

# Combat Action Economy & Skill Tier Progression

A character's number of available attacks and reactions in a single round is determined by their **Combat Skill Stage**:

| Rank Range | Skill Tier / Benchmark | Actions per Round | Focus Strike Bonus |
| :--- | :--- | :--- | :---: |
| **0** | Untrained | Full Round (1 basic action) | — |
| **1 – 5** | Novice / Studied | **1st Action** at base score | +2 |
| **6 – 10** | Trained / Professional | **2nd Action** at base score -5 | +3 |
| **11 – 15** | Expert | **3rd Action** at base score -10 | +4 |
| **16 – 20** | Master | **4th Action** at base score -15 | +5 |
| **21 – 25** | Grand Master | **5th Action** at base score -20 | +6 |
| **26 – 30** | Pinnacle | **6th Action** at base score -25 | +7 |

## Multiple Active Defenses
Characters may roll active defense checks against incoming attacks up to their Defense Skill rank limit, suffering a cumulative **-5 penalty** on each subsequent reaction within the same round.

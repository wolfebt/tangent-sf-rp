# Strike vs. Defense: Opposed vs. Unopposed Checks

## 1. Opposed Combat Check (Active Defense)
- **Attacker Roll**: d20 + Combat Skill + Ability Mod + Modifiers
- **Defender Roll**: d20 + Defense Skill + Agility Mod + Cover/Edge Modifiers
- **Resolution**: If Attacker > Defender, the strike hits. If Defender ≥ Attacker, the attack misses or is parried (**Defender wins all ties**).

## 2. Unopposed Combat Check (Static Defense / Unaware Target)
- Used when the target is incapacitated, surprised, restrained, or choosing not to actively defend.
- **Base Difficulty**: **CR 15 (Average)** for a medium-sized target at Short range.
- **Size Modifiers**: Miniscule (-32) to Colossal (+16).
- **Range Modifiers**: Point Blank (+5 Strike), Short (0), Medium (-5), Long (-10), Extreme (-15).

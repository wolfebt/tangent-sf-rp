# Occupational Archetypes & Multi-Classing

Every Occupation features distinct archetypes representing specific career specializations within the galaxy:

## Multi-Classing via Background Trait
Characters in Tangent SF RP do not follow rigid class tracks. Instead, multi-disciplinary characters (e.g., Combat Medic, Corporate Spy, Smuggler Pilot) are created by:
1. Selecting a primary Occupation for core SP and Recommended Feature discounts.
2. Selecting the **Background** common trait to import specialized traits from secondary Occupations.
3. Combining skill ranks from Origin, Species, and Occupation.

# Metafocus Levels (ML 0 to 6) & Civilizational Scale

| ML | Classification | Description | Typical Demographics |
| :---: | :--- | :--- | :--- |
| **0** | **Null** | No native metaphysical activity; dead zones. | Pure machine worlds. |
| **1** | **Rare** | Negligible ratio of practitioners; skepticism or fear. | Most baseline colonies. |
| **2** | **Selective** | Minorities and specialized monastic cults. | Syndicate PsiCorp, covert units. |
| **3** | **Cultured** | Widely accepted and integrated into society. | Auluran Clans, Dynasty, Impyrium. |
| **4** | **Standardized** | Commonplace everyday usage across civic life. | Alterian Enclave, Ascendancy. |
| **5** | **Advanced** | Deeply pervasive reality-shaping civilization. | Ancient xeno-sanctums. |
| **6** | **Deific** | Transcended cosmic scale (NPC/Progenitor only). | Cosmic entities. |

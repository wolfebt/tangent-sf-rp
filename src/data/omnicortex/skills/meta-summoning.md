# Summoning

Dimension discipline: Drawing entities, matter, and energetic constructs across dimensional boundaries.

### Mechanics & Rules
- **Governing Attribute**: Wisdom
- **Discipline Focus**: Dimension
- **Standard Check**: `2d10 + Summoning Rank + Wisdom Mod vs. Target DC / Resistance`.
- **Prerequisite**: Unlocked when character possesses the **Awakened** feature or relevant Metaphysical discipline training.
- **Strain Resolution**: Failing an invocation check by 5+ points deals non-lethal strain fatigue.

### Specialties
- **Planar**: Planar Minions
- **Aetheric**: Aetheric Servitors
- **Ephemeral**: Ephemeral Constructs
- **Extradimensional**: Extradimensional Storage
- **Planar**: Planar Invocations

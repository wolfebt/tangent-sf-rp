# Teleport

Dimension discipline: Instantaneous spatial relocation, portal anchors, and trans-dimensional folding.

### Mechanics & Rules
- **Governing Attribute**: Wisdom
- **Discipline Focus**: Dimension
- **Standard Check**: `2d10 + Teleport Rank + Wisdom Mod vs. Target DC / Resistance`.
- **Prerequisite**: Unlocked when character possesses the **Awakened** feature or relevant Metaphysical discipline training.
- **Strain Resolution**: Failing an invocation check by 5+ points deals non-lethal strain fatigue.

### Specialties
- **Blink**: Blink Relocation
- **Gateway**: Gateway Creation
- **Spatial**: Spatial Anchors
- **Trans-dimensional**: Trans-dimensional Folding
- **Slipstream**: Slipstream Evacuation

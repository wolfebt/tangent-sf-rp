# Tolerance

**Category**: Ability Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Stamina 1 (for Physical) or Wisdom 1 (for Mental).

## Description
The character's metabolism or psyche processes ongoing trauma much faster than the average being.

## Mechanics & Benefit
When suffering from an ongoing effect (such as poison, disease, paralysis, or mental domination) that allows periodic Resistance Checks to end the effect (e.g., "save every minute"), the time interval between checks is reduced to **1/2 the typical time**.  
  * *Usage:* A poison that normally allows a save once per hour allows this character to save every 30 minutes.

## Special Rules
This feature acts as a **\[Multiple\]** selection. You must choose Physical Tolerance (Fortitude) or Mental Tolerance (Will).

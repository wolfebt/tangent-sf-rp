# Mental Alacrity

**Category**: General Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Intellect 2, Lightning Calculator

## Description
The character thinks at hyperspeed, allowing them to perform mental tasks while others are still reacting.

## Mechanics & Benefit
You gain an additional **Mental Action** per round, provided you take no Physical actions that round.  
  * *Usage:* Useful for issuing commands, hacking, scanning, or using purely mental Psionics.

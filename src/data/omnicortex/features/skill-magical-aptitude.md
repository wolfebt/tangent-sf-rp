# Magical Aptitude

**Category**: Skill Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: None

## Description
The character has a knack for the arcane theory, even if they aren't a powerful caster.

## Mechanics & Benefit
Gain a **\+2 Bonus** to **Attune** checks and a **\+1 Bonus** to **Knowledge (Metaphysics)**.

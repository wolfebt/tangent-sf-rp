# Property Boon

**Category**: Special Features  
**Cost**: 2 CP  
**Prerequisites**: Specialist or Operator Standing  

## Description
A societal or factional endowment granting the character personal command or ownership of specialized equipment, vehicles, or biomorphic construct docking rights.

## Mechanics & Benefit
- **Wealth Allocation**: Grants a permanent **+4 bonus to Wealth** specifically earmarked for purchasing, customizing, or maintaining personal property, vehicles, biomorphic mecha frames, or mobile command units.
- **Requisition Authority**: Provides priority docking, biological refit, and hangar space within friendly faction installations.

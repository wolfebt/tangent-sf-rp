# Coordinated Assist

**Category**: General Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Intellect 1

## Description
The character is a natural team player or squad leader, adept at setting up allies for success.

## Mechanics & Benefit
When using the **Aid Another** action (Skill Synergy), you grant an additional **\+1 Bonus** to your ally's check.

## Special Rules
This feature is \[Ranked\] by Intellect. (Rank 2 grants \+2, etc.).

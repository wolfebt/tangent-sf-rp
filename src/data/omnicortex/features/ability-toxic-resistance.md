# Toxic Resistance

**Category**: Ability Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: None

## Description
The character possesses an aggressively robust lymphatic and metabolic filter system, enabling them to resist corrosive gases, virulent toxins, and predatory venoms.

## Mechanics & Benefit
The character receives a **+3 bonus on Fortitude saving throws** against all ingested, inhaled, contact, or injury-delivered toxins, poisons, and biochemical radiation. Additionally, successful saves against damaging poisons eliminate all secondary effects, and failed saves deal half the normal initial damage.

# Karmic Blessing

**Category**: Karma Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: None

## Description
The character has a larger destiny than most. Fate has stockpiled more luck for them to use.

## Mechanics & Benefit
Increase your **Maximum Karma Pool** by **\+2 Points**.  
  * *Default:* Characters typically start with 3 Max Karma. This feature raises that cap (e.g., to 5).

## Special Rules
This feature is **\[Multiple\]**. You may take it multiple times to keep expanding your pool.

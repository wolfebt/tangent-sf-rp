# Greater Precision Strike

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Improved Precision Strike, Combat Skill 16

## Description
A lethal blow delivered with absolute efficiency, concentrating mastery into one decisive hit.

## Mechanics & Benefit
As a **Standard Action**, make a single attack at your highest bonus. If it hits, deal **four times (4x)** the weapon's base damage dice.

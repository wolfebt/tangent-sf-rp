# Connected

**Category**: General Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Charisma 1

## Description
The character has friends in low (or high) places. They can call in favors for equipment, information, or safe houses.

## Mechanics & Benefit
You have a network of contacts.  
  * *Rank 1:* Street/Soldier level (Gangs, Grunts).  
  * *Rank 2:* Management/Lieutenant level (Shop owners, Squad leaders).  
  * *Rank 3:* Officer/Executive level (City officials, Corp VPs).  
  * *Rank 4:* Boss/Director level (Planetary Governors, Crime Lords).

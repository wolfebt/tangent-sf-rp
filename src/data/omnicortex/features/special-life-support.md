# Life Support

**Category**: Special Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: None

## Description
The character can survive in environments hostile to their biology.

## Mechanics & Benefit
You can breathe and function comfortably in a specific non-native environment.  
* **Options:** *Aquatic* (Breathe water), *Atmospheric* (Breathe exotic gas mixes), *Vacuum* (Can survive in void for limited time/hold breath 10x longer).

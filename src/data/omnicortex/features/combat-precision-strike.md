# Precision Strike

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Combat Skill 6

## Description
The character consolidates their focus into a single, devastatingly accurate strike rather than a flurry of iterative blows. Strike consolidation is strictly gated behind possessing this feature chain.

## Mechanics & Benefit
As a **Standard Action**, make a single attack at your highest bonus. If it hits, deal **two times (2x)** the weapon's base damage dice.

## Special Rules
**Note:** Only the base weapon dice are multiplied, not static bonuses (Attribute modifier, specialization, etc.).

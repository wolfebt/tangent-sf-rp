# Dual Skeletal Structure

**Category**: Defensive Features  
**Cost**: 2 CP  
**Prerequisites**: Endoskeleton and Exoskeleton  

## Description
The organism possesses an advanced hybrid skeletal system combining an internal articulated endoskeleton with a hardened, segmented outer chitinous shell. This dual-layer framework distributes kinetic shock and prevents catastrophic bone breakage.

## Mechanics & Benefit
- **Natural DR +5**: The character gains **+5 Damage Reduction (DR 5)** against all physical trauma (bludgeoning, piercing, slashing) and kinetic shockwaves.
- **Structural Integrity**: Immune to bone-shattering injuries and limb dislocation from mundane falls or crushing pressures.

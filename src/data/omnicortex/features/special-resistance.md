# Resistance

**Category**: Special Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Stamina 1

## Description
The character has a fortified immune system or supernatural resilience.

## Mechanics & Benefit
Gain a **\+2 Bonus** to saves against a specific hazard category: **Disease**, **Poison**, **Radiation**, or **Magic**.

## Special Rules
\[Multiple\] Can be taken for different hazards.

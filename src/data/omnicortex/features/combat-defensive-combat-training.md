# Defensive Combat Training

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Combat Skill 1

## Description
The character has trained to resist grappling and takedowns, using overall combat experience rather than just raw agility.

## Mechanics & Benefit
You gain a **\+4 Bonus to Defense** specifically against Combat Maneuvers (Trip, Disarm, Grapple, Bull Rush).

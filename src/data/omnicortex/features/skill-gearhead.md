# Gearhead

**Category**: Skill Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Engineering 1 or Mechanics 1

## Description
The character has an intuitive understanding of machinery, engines, and mechanical systems.

## Mechanics & Benefit
Gain a **\+2 Bonus** to all Mechanical-based **Knowledge**, **Operation**, and **Repair** checks.

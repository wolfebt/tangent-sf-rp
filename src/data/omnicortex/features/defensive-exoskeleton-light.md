# Exoskeleton (Light)

**Category**: Defensive Features  
**Cost**: 2 BP  
**Prerequisites**: Insectoid, Crustacean, or Synthetic Physiology  

## Description
A resilient chitinous carapace, overlapping chitin scales, or segmented composite shell covering the body. While lighter than combat plates, it effectively turns aside low-velocity shrapnel and blunt impacts.

## Mechanics & Benefit
- **Damage Reduction**: Provides natural **Damage Reduction DR (Strength + 2) x 2** (minimum **DR 6**) against bludgeoning, slashing, and piercing attacks.
- **Physical Deflection**: Reduces impact trauma from environmental collisions and light debris.

# Skill Specialization

**Category**: Skill Sub-Skill Mechanics  
**Cost**: 1 SP / 1 CP per Specialization Rank (Max Rank 10; same price as Base Skills)  
**Prerequisite**: Chosen Base Skill Rank 6 (Trained)

## Description
The character drills deep into a specific niche of a broad skill as a built-up sub-skill.

## Mechanics & Benefit
Choose a specialized sub-skill within the parent skill (e.g., *Ballistic: Sniper Rifles* or *Computers: Hacking*). Rather than granting a flat \+2, specializations are built-up sub-skills advancing independently from Rank 1 to 10 at 1 SP / 1 CP per rank (same price as base skills).  
* **Mechanics:** When making a check within that specialization, add **Base Skill Rank (0–20) \+ Specialization Rank (1–10)**, with **only one specialization viable per check**. This combination unlocks the effective **21–30** skill range (**Grand Master 21–25** & **Pinnacle 26–30**).

## Special Rules
\[Multiple\] Different specializations may be built up; max 1 applies per check.

# Improved Disarm

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Combat Expertise

## Description
The character knows how to twist a weapon out of an opponent's grip safely.

## Mechanics & Benefit
You gain a **\+2 bonus** on Disarm attempts. Attempting to Disarm an opponent does not provoke an Attack of Opportunity.

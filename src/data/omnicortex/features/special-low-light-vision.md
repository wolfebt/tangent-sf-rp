# Low Light Vision

**Category**: Special Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: None

## Description
The character's eyes magnify ambient light.

## Mechanics & Benefit
You can see in dim light (starlight, moonlight) as clearly as if it were bright daylight. You interpret color normally. You still cannot see in absolute darkness.

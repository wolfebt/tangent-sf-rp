# Improved Precision Strike

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Precision Strike, Combat Skill 11

## Description
A surgical strike that maximizes impact through superior anatomical or structural targeting.

## Mechanics & Benefit
As a **Standard Action**, make a single attack at your highest bonus. If it hits, deal **three times (3x)** the weapon's base damage dice.

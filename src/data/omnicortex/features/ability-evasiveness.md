# Evasiveness

**Category**: Ability Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Must possess the base Feature for the chosen Save (Lightning Reflexes, Great Fortitude, or Iron Will).

## Description
The character is adept at avoiding the brunt of area attacks or resisting the full efficacy of potent effects.

## Mechanics & Benefit
When subjected to an effect that allows a **Resistance Check** for **Partial Effect** (commonly taking half damage on a success), a successful check instead results in **No Effect** (or zero damage).  
  * *Usage:* If a dragon breathes fire (Reflex for half), a character with Evasiveness (Reflex) takes *no damage* if they succeed on the roll.

## Special Rules
This feature acts as a **\[Multiple\]** selection. You must purchase it separately for Reflex, Fortitude, or Will.

# Lightning Calculator

**Category**: General Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Intellect 1

## Description
The character is a living computer, able to perform complex mathematics instantly.

## Mechanics & Benefit
You perform mathematical calculations at **2x speed**. This applies to Astrogation, Engineering calculations, and Cryptography.

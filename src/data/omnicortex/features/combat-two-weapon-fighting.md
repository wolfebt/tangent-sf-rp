# Two-Weapon Fighting

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Agility 2, Combat Skill 2

## Description
The character is skilled in the art of using two weapons simultaneously, coordinating attacks to maintain offense while balancing defensive gaps.

## Mechanics & Benefit
You suffer only a \-2 penalty to Strike rolls when using an off-hand weapon (standard penalty is \-4).  
* **Purpose:** The foundation for all dual-wielding combat styles.

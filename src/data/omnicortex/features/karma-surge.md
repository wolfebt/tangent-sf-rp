# Surge

**Category**: Karma Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: \-

## Description
The character pushes their body and mind beyond standard limits, fitting more action into a moment than should be possible.

## Mechanics & Benefit
You gain **1 additional Standard Action** this round.  
  * *Usage:* This allows for a Move \+ Attack \+ Attack, or Move \+ Cast Spell \+ Attack. It breaks the standard action economy.

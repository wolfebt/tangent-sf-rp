# Uncanny Dodge

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Agility 4

## Description
The character reacts to danger before their senses fully process it.

## Mechanics & Benefit
You retain your **Agility bonus to Defense** even if you are caught **Flat-Footed** or struck by an **Invisible attacker**.

## Special Rules
This does not negate the advantage an attacker gets from Feinting (see Greater Feint).

# Acute Senses

**Category**: Sensory Features  
**Cost**: 2 BP  
**Prerequisite**: Awareness 1 or Wisdom 1  

## Description
The character possesses finely tuned sensory receptors, allowing them to detect subtle audio frequencies, pinpoint distant scent plumes, or resolve fine visual details well beyond normal mortal baselines.

## Mechanics & Benefit
Choose one sensory modality when taking this feature (e.g., **Scent**, **Hearing**, or **Vision**):
* Gain a **+4 Bonus** on all **Perception**, **Alertness**, and **Tracking** checks that utilize the chosen sense.
* Characters with *Acute Senses (Scent)* can distinguish specific individuals, detect decaying organic matter, and diagnose biochemical changes through smell alone.

## Special Rules
This feature may be selected multiple times, choosing a different sensory modality each time.

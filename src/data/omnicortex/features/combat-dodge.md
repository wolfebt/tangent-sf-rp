# Dodge

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Agility 1

## Description
The character is adept at dodging blows.

## Mechanics & Benefit
Gain a **\+1 Dodge bonus to Defense**.

## Special Rules
Dodge bonuses stack with other Dodge bonuses (but not with themselves). This bonus is lost if you are Flat-Footed.

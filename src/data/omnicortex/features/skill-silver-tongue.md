# Silver Tongue

**Category**: Skill Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Charisma 1, Diplomacy 1

## Description
The character knows exactly what to say to defuse a situation or make a friend.

## Mechanics & Benefit
When using Diplomacy to change an NPC's attitude, you improve it by **one additional step** (e.g., Hostile becomes Indifferent instead of Unfriendly).

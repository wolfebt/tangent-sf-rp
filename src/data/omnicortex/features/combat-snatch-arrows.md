# Snatch Arrows

**Category**: Combat Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Agility 4, Deflect Arrows

## Description
The character can catch arrows, bolts, or thrown weapons out of the air.

## Mechanics & Benefit
When using Deflect Arrows, if you have a free hand, you may catch the projectile instead of just deflecting it. You may immediately throw it back as a free attack (if it is a thrown weapon) or drop it.

# Influence

**Category**: Skill Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Charisma 2

## Description
The character has significant social pull within their faction or community.

## Mechanics & Benefit
Gain a **\+4 Bonus** to **Reputation** and **Favor** checks (a subset of Diplomacy used to acquire resources or assistance).

# Benefit (Authority)

**Category**: General Features  
**Cost**: 3 BP (2 BP if Suggested Feature, minimum 1 BP)  
**Prerequisite**: Associated Occupation (Soldier, Constable, Agent)

## Description
The character holds a recognized rank within a law enforcement or military organization, granting them legal power and jurisdiction.

## Mechanics & Benefit
You hold a specific rank.  
  * *Rank 1:* Deputy / Corporal (Local jurisdiction).  
  * *Rank 2:* Officer / Sergeant (Regional jurisdiction).  
  * *Rank 3:* Marshal / Lieutenant (Planet-wide jurisdiction).  
  * *Rank 4:* Agent / Commander (Interstellar/System-wide jurisdiction).

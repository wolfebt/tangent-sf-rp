# Attractive

**Category**: Skill Features  
**Cost**: 3 CP (2 CP if Suggested Feature, minimum 1 CP)  
**Prerequisite**: Charisma 2

## Description
The character possesses striking physical beauty or magnetic appeal that captures attention.

## Mechanics & Benefit
Gain a **\+2 Bonus** to all Social checks where physical appearance is a factor (e.g., Seduction, First Impressions).

## Special Rules
This feature is **\[Ranked\]** (Limited by Charisma score). Rank 2 grants \+4, etc.

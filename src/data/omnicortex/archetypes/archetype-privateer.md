# The Privateer

**Sphere**: Operatives (The Artisans)  
**Core Concept**: Combat Pilot / Skirmisher / Face  
**Chassis Allocation**: 80 BP (+3 Primary, +2 Secondary, Essential Skills & Signature Features)

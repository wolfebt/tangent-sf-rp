# Swarming

**Category**: Species Traits (Advanced)  
**Cost**: 2 BP  
**Type**: Combat  

## Description
Two members can share same square. If attacking same foe, considered flanking.

## Mechanics & Benefits
Up to two members of this species can occupy the exact same 5-foot tactical square. When both attack the same opponent in melee, they are automatically considered to be flanking that target.

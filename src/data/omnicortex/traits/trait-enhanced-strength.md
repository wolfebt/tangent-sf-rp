# Enhanced Strength

**Category**: TRAITS  
**Tier**: Advanced  
**Type**: Species Trait  
**BP Cost**: 2  

## Description
Biomechanical musculature and leveraged skeletal joints treat the organism as one size category larger when calculating lifting, carrying, dragging limits, and grappling resistance.

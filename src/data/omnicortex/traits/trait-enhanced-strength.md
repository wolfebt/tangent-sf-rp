# Enhanced Strength

**Category**: TRAITS
**Tier**: Advanced
**Type**: Species Trait
**CP Cost**: 2

## Description
Biomechanical musculature treating the creature as one size category larger for lift and carry.

## Mechanics & Benefit
Counts as 1 size category larger (Medium counts as Large) for lifting capacity, dragging limit, and grappling

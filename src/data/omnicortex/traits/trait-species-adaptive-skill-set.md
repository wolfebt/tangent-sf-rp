# Adaptive Skill Set

**Category**: Species Traits (Advanced)  
**Cost**: 2 BP  
**Type**: Trained (Ranked)  

## Description
4 point bonus allotted in a pool. Ranked.

## Mechanics & Benefits
Grants a flexible 4-point pool of skill bonuses that can be reassigned across trained skills during a Light Rest or preparation period. May be purchased multiple times (Ranked) to expand the pool by +4 points per rank.

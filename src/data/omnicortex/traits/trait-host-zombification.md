# Host Zombification

**Category**: TRAITS
**Tier**: Advanced
**Type**: Species Trait
**CP Cost**: 2

## Description
Swarm inhabits and mechanically puppets corpses or damaged biomorphic husks as armored shells.

## Mechanics & Benefit
Adopts host size, base Strength, and native DR; husk absorbs damage first as an ablative shell

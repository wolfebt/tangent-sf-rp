# Bonded Terrain

**Category**: Species Traits (Basic)  
**Cost**: 1 BP  
**Type**: Defensive  

## Description
+2 dodge bonus to AC when in a specific terrain type.

## Mechanics & Benefits
Select one specific terrain type (Forest/Jungle, Arctic/Tundra, Desert, Mountain/Rocky, Aquatic/Swamp, Urban/Arcology, Subterranean, or Void/Zero-G). While operating within that terrain, the character gains a permanent +2 dodge bonus to Armor Class (AC) and Defense.

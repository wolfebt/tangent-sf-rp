# Leaper

**Category**: TRAITS  
**Tier**: Advanced  
**Type**: Species Trait  
**BP Cost**: 2  

## Description
High-impact hydraulic leg anatomy allows the creature to always count as having a running start for jump distance, and grants Advantage on all checks for jumping, leaping, and dropping.

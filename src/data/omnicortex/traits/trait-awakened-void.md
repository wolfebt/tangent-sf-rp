# Awakened (Void)

**Category**: TRAITS  
**Tier**: Advanced  
**Type**: Species Trait  
**CP Cost**: 2  

## Description
Resonance with the deep void between the stars, entropic rifts, and spatial shadows.

## Mechanics
Grants innate access to the Attune skill, Void/Entropy metaphysical disciplines, and manipulation of dimensional shadows using Wisdom or Intellect as the primary governing attribute.

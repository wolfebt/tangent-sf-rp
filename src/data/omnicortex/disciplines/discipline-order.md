# Order Focus (Entropy)

Restoring biological patterns, cellular healing, critical stabilization, and abjuration wards.

### Mechanics
- **Parent Discipline**: Entropy
- **Healing**: `2d6 per Discipline Stage + 1d6 per Invocation Rank` (Restores Health / Vitality).
- **Stabilize**: Immediate reaction prevents death when character reaches 0 HP.
- **Restoration**: Cleanses poisons, diseases, and status conditions based on severity DC.

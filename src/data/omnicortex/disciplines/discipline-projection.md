# Projection Focus (Mental)

Sending telepathic thoughts, psionic domination commands, neural mind blasts, and altering memories.

### Mechanics
- **Parent Discipline**: Mental
- **Range**: Extended (`100ft x Rank`).
- **Mind Blast**: Inflicts `1d6 Psychic damage per Rank` + Stun condition (Will save for half).
- **Domination**: Forces target to obey verbal commands (Will save negates).

# Chaos Focus (Entropy)

Accelerating decay, breaking molecular bonds, inflicting curses, and channeling lethal negative energy.

### Mechanics
- **Parent Discipline**: Entropy
- **Damage**: `2d6 per Discipline Stage + 1d6 per Invocation Rank` (Necrotic / Chaos damage; ignores non-magical hardness and armor DR).
- **Curse**: Inflicts Disadvantage on target rolls for 1 round per Rank (Will save negates).

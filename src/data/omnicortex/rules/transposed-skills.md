# Transposed Skill Base

While every skill has a default governing Ability Score, unique character concepts, cybernetic interfaces, or psionic disciplines may justify swapping the base attribute.

## Guidelines & GM Approval
- **Permanent Transposition**: Reflects innate biological traits or heavy cybernetic links (e.g., using *Intellect* instead of *Agility* for Piloting via a neural direct-feed).
- **Situational Transposition**: Reflects specific techniques (e.g., using *Agility* instead of *Strength* for Melee with a rapier via Weapon Finesse).
- **Game Balance**: Must make narrative sense and cannot be used solely to min-max without corresponding character investment.

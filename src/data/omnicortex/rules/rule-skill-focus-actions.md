# Skill Focus & Action Economy Progression

**Category**: Core Combat Rules & Tables

Combat capability is defined by Skill Tier. As a character gains Ranks, they gain additional actions and Focus Strike bonuses.

| Rank Range | Actions | Benchmark / Title | Focus Bonus |
| :--- | :--- | :--- | :---: |
| **0** | Full Round Action | Untrained | — |
| **1 – 5** | 1st action at base score | Novice / Studied | **+2** |
| **6 – 10** | 2nd action at base score -5 | Professional / Trained | **+3** |
| **11 – 15** | 3rd action at base score -10 | Expert | **+4** |
| **16 – 20** | 4th action at base score -15 | Master | **+5** |
| **21 – 25** | 5th action at base score -20 | Grand Master | **+6** |
| **26 – 30** | 6th action at base score -25 | Pinnacle | **+7** |

### Multiple Active Defenses
A character may also make as many Active Defense checks as allowed based on their Defense Skill Rank (all with a **-5 subsequent penalty** after the first reaction: 1st base, 2nd -5, 3rd -10, etc.).

# Advantage & Disadvantage Mechanics

## Rolling with Advantage
- Roll two sets of **2d10** (or more with multiple sources) and select the **highest total**.
- **Stacking Advantage**: Each additional source of advantage adds an extra 2d10 set to the roll pool.
- **Karma Point Trigger**: Spending 1 Karma Point grants Advantage on any single check.

## Rolling with Disadvantage
- Roll two sets of **2d10** and select the **lowest total**.
- **Stacking Disadvantage**: Multiple disadvantage penalties add additional 2d10 sets, taking the lowest of all rolled.

## Mutual Cancellation
Advantage and Disadvantage cancel each other out on a 1-for-1 basis. If a check has 1 source of Advantage and 1 source of Disadvantage, roll a standard single set of 2d10.

# Limb Damage: Disabled Threshold (1/3 Health)

**Category**: Core Combat Rules & Tables

## Mechanics
- **Threshold**: Taking **1/3rd of Health Score** in damage to a limb disables it (or causes Unconsciousness if dealt to the Head).
- **Stamina Check**: The character must pass a **Stamina Check with CR = 10 + Damage Taken** to keep using the limb.
- **Debilitating Penalties**:
  - **Head**: **-4 on all actions**.
  - **Arm**: **-4 Strength and Agility** for actions using that arm.
  - **Leg**: **Half Ground Speed** and **no Rush Maneuver**.
- **Healing**: Medical attention or Metaphysics is required to properly restore function.

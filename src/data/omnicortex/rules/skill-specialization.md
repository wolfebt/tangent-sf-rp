# Skill Specialization System

Skill Specialization allows deep focus within a narrow sub-field of a skill (e.g., *Melee (Swords)* or *Medicine (Surgery)*).

## Specialization Rules
- **Prerequisite**: Character must possess **Rank 6 or higher (Trained)** in the base skill.
- **Independent Advancement**: Specialization ranks advance independently of the base skill (Max Level 10).
- **Stacking Bonus**: Specialization level is added directly to the base skill check for related tasks.
- **Exceeding the Cap**: Adding the Specialization bonus to a Rank 20 Master allows a character to reach **Rank 30 Pinnacle** benchmarks.
- **Single Specialization Limit**: Only one specialization bonus may apply to a single roll.

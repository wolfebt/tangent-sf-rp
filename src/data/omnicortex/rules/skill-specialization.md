# Skill Specialization System

Skill Specialization allows deep focus within a narrow sub-field of a skill (e.g., *Melee (Swords)* or *Medicine (Surgery)*). Specializations do **not** grant a flat `+2` bonus; they are built-up sub-skills advancing independently up to Rank 10.

## Specialization Rules
- **Base Skill Range**: Base Skill Ranks progress from **0 to 20** (capping at Master `16–20`, starting creation cap `11`).
- **Prerequisite**: Character must possess **Rank 6 or higher (Trained)** in the base skill.
- **Sub-Skill Cost & Cap**: Specialization ranks advance independently from **Rank 1 to 10** at **1 SP / 1 CP (1 AP) per rank**—the exact same price as base skills.
- **Additive Total (`Skill + Specialization`)**: Specialization rank adds directly to the Base Skill Rank on checks within its scope.
- **Unlocking the 21–30 Range**: Combining Base Skill (`0–20`) + Specialization (`1–10`) unlocks **Grand Master (`21–25`)** and **Pinnacle (`26–30`)** mastery.
- **Single Specialization Limit**: Only **one** specialization is viable and may apply to any single check.

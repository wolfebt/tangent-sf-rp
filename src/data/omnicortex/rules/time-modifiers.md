# Time Modifiers: Meticulous vs. Rushed

The time dedicated to a task directly modifies the check result:

## Meticulous Checks (Taking Extra Time)
Taking extra time allows careful measurement and double-checking:
- **+50% Time**: **+2 Bonus**
- **+100% Time**: **+4 Bonus**
- **+150% Time**: **+6 Bonus**
- **+200% Time**: **+8 Bonus** (Maximum)

*Note: Experts and Masters gain increased bonuses per time stage (+3 and +4 per stage).*

## Rushed Checks (Hasty Execution)
Forcing rapid completion increases mistake probability:
- **3/4 Base Time (-25%)**: **-2 Penalty**
- **1/2 Base Time (-50%)**: **-4 Penalty**
- **1/4 Base Time (-75%)**: **-8 Penalty**

## Untrained Penalties
When an Untrained character (Rank 0) rushes or takes extra time, the modifiers are shifted **1 step worse**.

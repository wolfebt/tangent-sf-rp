# Skill Points Economy & Sources

In Tangent SF RP, Skills represent a character's training, experience, and practical expertise. Build Points (BP) are the primary currency used during character creation.

## Build Point Costs
- **Base Cost**: Every Skill Rank costs **1 Build Point (BP)** to acquire during character creation.
- **Maximum Starting Rank**: The maximum starting Skill Rank is **Rank 11** (Expert Tier cap).
- **Post-Creation Advancement**: Skills advance at a rate of 1 point per session/experience reward.

## Skill Allotments by Character Phase
1. **Species**: Grants baseline skill bonuses or skill points reflecting cultural educational standards (e.g., Humans receive 20 SP or bonus points).
2. **Faction**: Grants **20 Skill Points** tailored to faction-suggested areas of expertise.
3. **Origin**: Grants **20 Skill Points** corresponding to homeworld upbringing.
4. **Occupation**: Grants **25 Skill Points** focused on professional career training.
5. **Tech & Meta Levels**: Societies with higher TL/ML grant additional specialized skill points.

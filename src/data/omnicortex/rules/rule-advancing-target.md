# Edge: Advancing Target

**Category**: Core Combat Rules & Tables

## Mechanics
Target approaching without Cover or Evasion.
- **Extra Attack**: Defending combatant gains an Extra Attack on the target at **-5 to Strike**.
- **Initiative Reroll**: Re-roll Initiative if successfully moved into Melee.

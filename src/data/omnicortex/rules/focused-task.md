# Focused Task (Concentration Mode)

A character may voluntarily enter an intense state of total focus when performing a critical, delicate task.

## Mechanics
- **+2 Task Bonus**: Grants **+2 Bonus** to the focused skill check.
- **-5 Situational Penalty**: Imposes a **-5 Penalty** to all other checks, passive Defense, and Perception/Alertness.
- **Duration**: Remains in effect for the full duration of the task. If interrupted, the focus is broken.

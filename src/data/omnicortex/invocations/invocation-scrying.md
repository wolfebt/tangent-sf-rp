# SCRYING Invocation

**Category**: Invocations  
**Discipline**: Mental

## Description & Ritual Details
Classification: Mental (Sense) | Sensory | \[Remote Viewing\] \[Divination\]  
Parameters:
* **Base Difficulty:** 20  
* **Time:** 10 Minutes  
* **Range:** Unlimited  
* **Area:** Sensor Point  
* **Duration:** Concentration  
* **Resistance:** Will Save (if target is a creature)
Effect Description:  
Creates an invisible psychic sensor to see/hear a distant location.  
**Scaling Function:**
* **Clarity:** Sensor visibility reduces (DC to spot increases by \+2 per Stage).  
* **Senses:** At Stage 3+, can use Darkvision/Special Senses through the sensor.

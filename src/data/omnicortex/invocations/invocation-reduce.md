# REDUCE Invocation

**Category**: Invocations  
**Discipline**: Matter

## Description & Ritual Details
Classification: Matter (Transmutation) | Utility/Debuff | \[Size\] \[Shrink\]  
Parameters:
* **Base Difficulty:** 15  
* **Time:** Standard Action  
* **Range:** Close  
* **Area:** Single Creature  
* **Duration:** 1 Minute per Stage  
* **Resistance:** Fortitude (Negates)
Effect Description:  
Decreases the target's size category.  
**Scaling Function:**
* **Magnitude:** Decreases Size by 1 Category per 2 Stages.  
* **Defense:** AC/Stealth Bonus \= \+2 per Category decreased.

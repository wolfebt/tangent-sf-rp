# CLOUD Invocation

**Category**: Invocations  
**Discipline**: Energy

## Description & Ritual Details
Classification: Energy (Elemental) | Environmental | \[Mobile\] \[Area\]  
Parameters:
* **Base Difficulty:** 18  
* **Time:** Standard Action  
* **Range:** Medium (100ft)  
* **Area:** 20ft Radius Cloud  
* **Duration:** Concentration \+ 1d4 Rounds  
* **Resistance:** Fortitude Save (Negates secondary effects)
Effect Description:  
Creates a rolling bank of fog, steam, or toxic gas. Move Action to move cloud 20ft.  
**Scaling Function:**
* **Damage:** 1d4 Elemental Damage per Stage (DoT).  
* **Obscurement:** Vision penalty increases per Stage (Concealment \-\> Total Concealment).

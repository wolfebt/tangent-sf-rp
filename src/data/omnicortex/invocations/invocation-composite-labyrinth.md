# Spatial Labyrinth (Composite Invocation)

**Category**: Composite Invocations  
**Requisite Disciplines**: Illusion + Dimension

## Mechanics & Reality Manipulation
Bends local dimensions into an infinite, shifting sensory maze from which enemies cannot escape.

## Invocation Rules
- Invocation Level is added to the **lowest** of the requisite Discipline Skills used.

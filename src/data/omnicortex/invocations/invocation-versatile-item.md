# VERSATILE ITEM Invocation

**Category**: Invocations  
**Discipline**: Matter

## Description & Ritual Details
Classification: Matter (Transmutation) | Utility | \[Minor\] \[Polymorph\]  
Parameters:
* **Base Difficulty:** 10  
* **Time:** Standard Action  
* **Range:** Touch (Personal Item)  
* **Area:** Single Object  
* **Duration:** 1 Minute  
* **Resistance:** None
Effect Description:  
Changes a chosen personal item into another item of the same cost or lower. (e.g., Turning a Knife into a Screwdriver, or a Rope into a Net).

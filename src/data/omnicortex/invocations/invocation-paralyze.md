# PARALYZE Invocation

**Category**: Invocations  
**Discipline**: Mental

## Description & Ritual Details
Classification: Mental (Projection) | Crowd Control | \[Hold\] \[Motor Control\]  
Parameters:
* **Base Difficulty:** 18  
* **Time:** Standard Action  
* **Range:** Extended  
* **Area:** Single Creature  
* **Duration:** Rounds/Level  
* **Resistance:** Will Save (Negates)
Effect Description:  
Severs the connection between the target's mind and body, freezing them in place.  
**Scaling Function:**
* **Duration:** 1 Round per Stage per level.  
* **Quantity:** Number of targets \= 1 per Stage.

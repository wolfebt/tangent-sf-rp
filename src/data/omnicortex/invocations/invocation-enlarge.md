# ENLARGE Invocation

**Category**: Invocations  
**Discipline**: Matter

## Description & Ritual Details
Classification: Matter (Transmutation) | Buff | \[Size\] \[Growth\]  
Parameters:
* **Base Difficulty:** 15  
* **Time:** Standard Action  
* **Range:** Close  
* **Area:** Single Creature  
* **Duration:** 1 Minute per Stage  
* **Resistance:** Fortitude (Negates if unwilling)
Effect Description:  
Increases the target's size category.  
**Scaling Function:**
* **Magnitude:** Increases Size by 1 Category per 2 Stages (Max \+2).  
* **Power:** Strength Bonus \= \+2 per Category increased.

# SPEED Invocation

**Category**: Invocations  
**Discipline**: Matter

## Description & Ritual Details
Classification: Matter (Enhancement) | Buff | \[Movement\] \[Velocity\]  
Parameters:
* **Base Difficulty:** 15  
* **Time:** Standard Action  
* **Range:** Touch  
* **Area:** Single Creature  
* **Duration:** 1 Minute per Stage  
* **Resistance:** None
Effect Description:  
Increases the target's base movement rate.  
**Scaling Function:**
* **Magnitude:** Base Speed increases by \+10ft per Stage.  
* **Initiative:** Grants \+1 Bonus to Initiative per Stage.

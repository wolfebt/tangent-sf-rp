# ANIMATE OBJECT Invocation

**Category**: Invocations  
**Discipline**: Matter

## Description & Ritual Details
Classification: Matter (Enhancement) | Utility/Combat | \[Construct\] \[Minion\]  
Parameters:
* **Base Difficulty:** 18  
* **Time:** Standard Action  
* **Range:** Close  
* **Area:** Single Object  
* **Duration:** Concentration  
* **Resistance:** None
Effect Description:  
Imbues an inanimate object with mobility and a semblance of life.  
**Scaling Function:**
* **Power:** Max Object Size \= Small (Stage 1\) \-\> Medium (2) \-\> Large (3) \-\> Huge (4).  
* **Damage:** Object Slam Damage \= 1d6 per Stage.

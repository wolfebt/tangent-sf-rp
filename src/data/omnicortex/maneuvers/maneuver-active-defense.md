# Active Defense

**Category**: Combat Maneuvers  
**Action Type**: Reaction Action

## Mechanics
- **Reaction**: Roll an active Defense check (Agility + Defense Skill) to replace static Defense or negate incoming strikes and maneuvers.
- **Golden Rule**: **Defender wins all ties**.
- **Iterative Reactions**: Multiple reactions permitted based on Defense Skill Rank. Each consecutive active defense after the first suffers a **cumulative -5 penalty** (1st: base, 2nd: -5, 3rd: -10, 4th: -15, etc.).

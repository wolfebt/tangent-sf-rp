# Clown

**Category**: Hindrances & Disadvantages  
**BP Granted**: 2 BP  
**Type**: Social

## Description
A known compulsive jokester, prankster, or class clown who struggles to project authority.

## Mechanics & Severity
### Mechanics
- **-2 Penalty** on all checks to be taken seriously (Intimidation, formal Persuasion, battlefield Command).
- NPCs naturally assume the character is joking, bluffing, or being sarcastic.

# Slow (Disadvantage)

**Category**: Species Disadvantages (CP Reduction)  
**CP Refund**: +2 CP (Cost: -2 CP)  
**Type**: Movement  

## Description
Base Speed -10 feet. (CP Gain) *

## Mechanics & Severity
The species suffers a -10 foot penalty to their base ground movement speed (reducing standard 30 ft speed to 20 ft). Note: A species may only select one base speed modifier trait.

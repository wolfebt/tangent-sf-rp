# **99.Schema.ArchitectureAndBase — Tier 3 Structure & Base JSON Schema**
## **1. PURPOSE & ARCHITECTURAL ROLE**
This schema validates all Tier 3 Static Buildings, Outposts, Arcologies, and Mobile Structures engineered via 99.Tech.Architecture.ForgeProtocol.md. It enforces:

1. **Footprint & Verticality Scaling:** `total_modules = base_modules * stories` and `final_sp = base_sp * stories * tl_sp_multiplier`.
2. **The 10:1 Module-to-Mount Conversion:** Unspent architectural Modules partition into `10 Mounts` each for hardpoints (armor, shields, turrets, sensors).
3. **The 20% Mobile Structure Chassis Tax:** Mobile structures reserve `ceil(0.20 * total_modules)` for propulsion.
4. **Highest Complexity Rule & EUFT Linear Micro-Modifiers:** `final_crafting_cr = max(base_footprint_cr + height_mod + frame_mod + env_mod, highest_installed_module_cr)`.

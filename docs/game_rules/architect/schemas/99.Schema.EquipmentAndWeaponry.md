# **99.Schema.EquipmentAndWeaponry — Tier 1 Weaponry, Armor Layering & Cosmic Entity JSON Schema**

## **1. PURPOSE & ARCHITECTURAL ROLE**

This file defines the canonical JSON Schema for validating Tier 1 personal armaments (`99.Tech.Weaponry.ForgeProtocol.md`, `99.Tech.Weaponry.Catalog.md`), personal armor suits (`99.Tech.Armor.DesignAndCatalog.md`, `2.00.Armor.md`), and non-corporeal Cosmic Entities (`05.00.CosmicEntities.md`). When BASTION generates, audits, or exports any weapon, armor loadout, or Cosmic Entity profile, it validates the payload against this schema to guarantee:

1. **Deterministic 2d10 Combat & Critical Math:** All weapon attack rolls resolve on `2d10 + Skill Rank + Attribute Modifier + Modifiers vs. CR`. Critical Hits (`Natural 20`, or expanded threat range `19`, `18`) add `+10` to the rolled dice value (`20 -> 30`, `19 -> 29`), double base weapon damage dice (`2x Base Weapon Damage Dice`), and trigger the weapon's Critical Effect. Fumbles (`Natural 2` / double-1s on `2d10`) replace the rolled dice value with a flat `-10` (`Base Score - 10`) and trigger a Complication.
2. **Diminishing Returns Armor Stacking & Stamina Base Toughness:** When multiple armor Damage Reduction (`DR`) layers apply across biological, subdermal/cybernetic, metaphysical, and wearable layers, use the **single highest DR value** as the base and add **`+1 DR` per stage of 5** (`0 = +0`, `1–5 = +1`, `6–10 = +2`, `11–15 = +3`, `16–20 = +4`, i.e., `ceil[Layer DR / 5]`) **calculated separately for each additional layer** (`effective_domain_dr = highest_dr + sum(ceil(additional_layer_dr / 5))`), while overlapping worn garments still apply their movement and agility friction penalties. Incoming wound damage is reduced by `Effective Stacked DR + Stamina Modifier (Base Toughness)` after subtracting `Weapon Penetration`.
3. **EUFT Valuation & UDU Capacity:** Item credit values follow `Value = 10 * 4^(CR / 5)` with Linear Micro-Modifiers (`+1 CR = x1.30`, `+2 CR = x1.75`, `+3 CR = x2.30`, `+4 CR = x3.00`, `-1 CR = x0.75`), `50%` Pristine Material Cost, `10%` Scrap Value (`5x` Scrap Mass required for salvage crafting), and the `10:1` UDU hierarchy (`10 Nodes = 1 Socket`, `10 Sockets = 1 Mount`, `10 Mounts = 1 Module`).
4. **Cosmic Entity Non-Corporeal Architecture (`05.00.CosmicEntities.md`):** Validates non-corporeal Resonance entities under Universal Straight CP Pricing (`+5 CP` per `+1` Attribute, `1 CP` per `1` Skill Rank), `Base 60 Structure Points (SP)` (`+5 SP` per `1 CP`, zero Stamina scaling), `Stability Points = WIS + 5`, Species-level Hindrance exemption (`No Physical Form [-75 CP]` exempt from the `+10 CP` personal hindrance cap), and Aetherite Core avatar projection scaling.

# **99.Schema.PlanetarySystem — Star System & World Code JSON Schema**
## **1. PURPOSE & ARCHITECTURAL ROLE**
This schema validates procedural and canonical Star Systems, Planetary World Codes, Economic Trade Classifications, and Environmental Hazards from 99. MODULAR PLANETARY MATRIX.md and 04.00.StarAtlasAndGazetteer.md.

# **99.Schema.MechaAndAutomata — Tier 2 Vehicle, Mecha & Automata JSON Schema**
## **1. PURPOSE & ARCHITECTURAL ROLE**
This schema validates all Tier 2 Mecha, Vehicles, Variable Form Technology (VFT) units, and AI-piloted Automata created via 99.Tech.Mecha.ForgeProtocol.md and 99.Tech.Mecha.AutomataAndGear.md. It enforces:

1. **Pre-Calculated Structure Points (SP):** Vehicle SP comes directly from the Size Category table and is never multiplied a second time by the Scale Multiplier.
2. **Active Scale Multiplier:** Applied exclusively to weapon damage dice, tactical speed, and weapon range.
3. **Garaging UDU Conversion:** `garaging_mounts_required = scale_multiplier` (`10 Mounts = 1 Architectural Module`).
4. **Automata Initiative & Skill Caps:** When `is_automata = true`, `initiative_bonus = AGI + Alertness + processor_rating`, `total_skill_ranks = (PR + 1) * 5`, and `max_skill_rank = max(5, PR * 3)`.

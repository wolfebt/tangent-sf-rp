## **SKILL SPECIALIZATION PARAMETERS MATRIX**

| Parameter | Canonical Rule | Mechanical Effect |
| :--- | :--- | :--- |
| **Prerequisite** | Base Skill Rank `6+` (Trained) | Requires professional foundational competence before specializing. |
| **Sub-Skill Cost** | `1 SP` / `1 CP` per Rank (same price as Base Skills) | Built-up sub-skill (not a flat `+2` bonus or `3 CP` feature tax); advances independently from the base skill. |
| **Base vs. Specialization Cap** | Base Skill `0–20` + Specialization `1–10` | Base skills cap at Rank `20` (`Master`); specializations cap at Rank `10` (`+10` ranks). |
| **Unlocking Ranks 21–30** | Base Skill (`0–20`) + `1` Specialization (`1–10`) = `21–30` | Combining Base Skill + Specialization unlocks `Grand Master` (`21–25`) and `Pinnacle` (`26–30`) mastery. |

# **SKILL SPECIALIZATION**

Skill Specialization in Tangent enables players to enhance their characters' expertise within a specific skill. Rather than granting a flat static modifier (such as `+2`), a Specialization is a built-up sub-skill advancing independently from Rank `1` to `10` at the exact same price as base skills (`1 SP` / `1 CP` per rank). Adding a Specialization to its parent Base Skill (`0–20`) is how operators surpass the Rank `20` base skill ceiling to enter the `21–30` mastery range (`Grand Master` and `Pinnacle`).

  

## **Choosing a Specialization**

When a character develops a Skill Specialization, they choose a specific sub-skill focus within the parent skill. For example, a character with the "Melee" skill might build a specialization in "Swordfighting" or "Polearms," while a character with the "Medicine" skill might specialize in "Surgery" or "Herbalism."

  

## **Bonus Ranks**

The character gains sub-skill ranks in their chosen specialization (`Rank 1–10`), adding their current specialization rank directly to their Base Skill Rank (`0–20`). These specialization ranks apply only to checks within that specialization's scope.

  

## **Limited Scope**

While Skill Specialization provides higher effective skill totals in the chosen niche, it applies strictly within that sub-discipline; broader uses of the skill rely on the Base Skill Rank (`0–20`) alone.

  

## **Prerequisite**

To acquire a Skill Specialization, the character must already have a rank of 6 or higher (Trained level) in the chosen base skill. This ensures a foundation of knowledge before specializing.

  

## **Cost**

Specialization ranks cost `1 SP` / `1 CP` (or `1 AP` during advancement) per rank—the exact same price as regular base skill ranks, with no separate feature unlock surcharge.

  

## **Independent Level**

The level of Specialization advances separately from the base skill rank. This means a character can continue to improve their specialization (up to Rank `10`) even if their parent Base Skill has not yet reached Rank `20`.

  

## **Maximum Level**

Base Skills have a maximum rank of `20`, and Specializations have a maximum rank of `10`. This structure ensures that reaching effective ranks `21–30` requires dedicated sub-skill mastery rather than generic base ranks alone.

  

## **Bonus**

Adds the Specialization Rank (`1–10`) directly to the character's Base Skill Rank (`0–20`) on applicable skill checks (`Effective Rank = Base Skill + Specialization`).

  

## **Exceeding the Maximum**

By adding a Specialization (`1–10`) to the Base Skill (`0–20`), a character can exceed the normal Base Skill maximum of `20` and enter the `21–30` range—unlocking **Grand Master (`21–25`)** and **Pinnacle (`26–30`)** mastery.

  

## **Limited Use**

Only **one** Specialization is viable and can be applied to any single skill check (`Base Skill + 1 Specialization`). Characters cannot stack multiple specializations on the same roll, though Skill Synergy from a separate skill can still apply.

  

*Example*

*A character with a rank of 8 in the "Computer" skill might acquire a Skill Specialization in "Hacking." This would represent their focused expertise in breaking into computer systems and bypassing security measures. The Specialization bonus would enhance their effectiveness in hacking-related skill checks, allowing them to attempt more complex tasks and potentially outperforming other characters with higher Computer skill ranks but lacking this specialization.*

# **99.Schema.OperatorCharacter — Operator Stat-Block JSON Schema & Validator**
## **1. PURPOSE & ARCHITECTURAL ROLE**
This file defines the canonical JSON Schema for Volume I Operator (Player) and Volume II Modular NPC Character Sheets. When BASTION generates, audits, or exports a character build, it validates the output against this schema to guarantee:

1. **Starting Budget Compliance:** `150 CP` total (`80 CP` Archetype Chassis + `70 CP` Customization) for Tier 1 Operatives (or Tier 2 `200-299 CP`, Tier 3 `300-449 CP`, Tier 4 `450+ CP`).
2. **Background Allocation Compliance:** `20 SP` Faction + `20 SP` Origin + `20 SP` Occupation = `60 Skill Ranks`, `4 Features`, and `4 Traits` at `0 CP`.
3. **Zero Stamina Pool Scaling:** Biological characters start at `Base 30 Vitality` and `Base 30 Health` (Synthetics at `Base 60 SP`), increased strictly by `+5 per 1 CP` spent. Stamina (`STA`) applies exclusively to **Base Toughness** and **Fortitude Save** (`Stability Points = STA + 5`).
4. **Personal Hindrance Cap:** Maximum `+10 CP` from personal Hindrances (Species-level disadvantages and Stigmas are tracked separately and exempt).

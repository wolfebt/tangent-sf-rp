## 2026-10-10 - Insecure Randomness in Invite Codes\n**Vulnerability:** Weak random number generation using Math.random() for squad invite codes in src/services/squadService.js.\n**Learning:** Math.random() is predictable and unsafe for security contexts like invite codes. Also discovered that many string selection algorithms suffer from modulo bias unless the character set length is a power of 2.\n**Prevention:** Use globalThis.crypto.getRandomValues() or window.crypto.getRandomValues() for all security-sensitive random generation, and ensure string character sets are sized as powers of 2 (e.g. 32 chars) when using bitwise AND selection.

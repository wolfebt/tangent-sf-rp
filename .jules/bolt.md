## 2024-05-24 - [Universal Catalog Filtering Optimization]
**Learning:** For client-side search filtering of large arrays (e.g., catalogs, compendiums, and rosters), processing thousands of items with `.filter()` and `.toLowerCase().includes()` inside `useMemo` on every keystroke causes main thread blocking and UI stutter. React attempts to immediately re-render the heavy list along with the controlled input state (`searchQuery`).
**Action:** Used `useDeferredValue` on the `searchQuery` state for filtering. By depending on `deferredSearchQuery` in the `useMemo` block, React categorizes the heavy filtering and subsequent re-render as a low-priority update, ensuring the text input remains responsive and lightning fast while typing. Apply this pattern to other large client-side filtered data lists in the app (like `MetaphysicsModal` and `RosterModal` in the future if they experience similar stutters).
